Open review items of the sandbox, to close before P2 exit:
- `execve` is in the adapter allow-list because the spawner execs after the filter is installed. Landlock limits it to the read paths. A launcher that execs before filtering would remove it.
- `poll`, `access`, `arch_prctl`, `readlink(at)`, `faccessat(2)`, `fcntl`, `getdents64` were added while tracing the fake adapter's start-up; each needs a justification in the profile review.
- The fault test skips silently without a delegated scope unless `POWERMUG_REQUIRE_SANDBOX=1` is set. The CI runner that tests the sandbox must set it. Run the test binary under `systemd-run --user --scope -p Delegate=yes`, not `cargo test` (cargo itself would sit in the scope and break the cgroup rule).
- `deny.toml` accepts `MIT-0` and `Zlib` (both permissive, pulled by `jsonschema`). Confirm with the owner.
